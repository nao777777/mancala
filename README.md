# マンカラ

木のボードとガラス玉で遊ぶマンカラ（カラハ式）のWebゲームです。依存ライブラリなし、1枚のHTMLで動きます。

- CPU対戦（やさしい／ふつう／むずかしい、先攻・後攻・ランダム）とヒント
- ふたりで対戦（同じ端末で交代）
- ルール設定（各穴3〜6個、横取りあり／なし）
- パズル（10問）、対局の振り返り（手の評価とゴール差のグラフ）
- 着せ替え（石・ボード・敷物）、対局の自動保存と「続きから」
- チュートリアル（6ステップ）とルール説明

## 遊ぶ

`docs/index.html` をブラウザで開くか、GitHub Pages で公開したURLにアクセスしてください。

## ルール（カラハ式）

- 各穴に4個ずつ、合計48個。石は反時計回りに1個ずつ配る。相手のゴールは飛ばす。
- 最後の1個が自分のゴールに入ったら、もう1回。
- 最後の1個が自分側の空の穴に入り、向かいに石があれば、両方を自分のゴールへ（横取り）。
- どちらかの陣地が空になったら終了。残りはそれぞれの持ち主のゴールへ。多い方が勝ち。

## 開発

```sh
npm test        # ルールエンジンとCPUのテスト
npm run build   # src/ を結合して docs/index.html と dist/mancala.html を作る
```

| パス | 内容 |
| --- | --- |
| `src/engine.js` | ルールエンジン（純粋関数） |
| `src/ai.js` | CPU（ランダム寄り／ミニマックス／αβ反復深化）。画面ではWeb Workerで動かす |
| `src/puzzles.js` | パズルの問題・達成判定・解答器 |
| `src/app.js` | 画面・アニメーション・音・チュートリアル |
| `src/style.css`, `src/template.html` | 見た目とマークアップ |
| `assets/` | アプリアイコン |
| `docs/index.html` | GitHub Pages 用のビルド結果 |
