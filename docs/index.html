ルール説明

このゲームは「カラハ」と呼ばれる、いちばん広く遊ばれているマンカラのルールです。

準備

ボードには穴が12個（自分の陣地6つ、相手の陣地6つ）と、両はしに細長いゴールが2つあります。手前の6つがあなたの陣地、右はしがあなたのゴールです。はじめに各穴へ石を4個ずつ、合計48個入れます。

配り方

自分の番になったら、自分の陣地の穴をひとつ選びます。中の石を全部取り、右どなりの穴から反時計回りに1個ずつ入れていきます。自分のゴールにも入れますが、相手のゴールには入れずに飛ばします。

もう一回

最後の1個がちょうど自分のゴールに入ったら、続けてもう1回遊べます。何回でも続けられるので、うまくつなげると一気に差がつきます。

横取り

最後の1個が自分の陣地の空っぽの穴に入り、その向かいの穴に相手の石があれば、その1個と向かいの石をまとめて自分のゴールに入れます。向かいが空っぽなら横取りはできません。

終わりと勝ち負け

どちらかの陣地の6つの穴がすべて空になったら、ゲーム終了です。残っている石は、それぞれの陣地の持ち主のゴールに入ります。ゴールの石が多い方の勝ち。同じ数なら引き分けです。

メニューの「ルール設定」で、はじめの石の数（各穴3〜6個）と横取りのあり／なしを変えられます。標準は各穴4個・横取りありです。

勝つためのコツ

  • ゴールまでの距離と同じ数の石が入った穴を探しましょう。右はしの穴に1個、その左に2個…なら「もう一回」になります。
  • 空っぽの穴は横取りのチャンスです。相手の番の前に、自分の空き穴の向かいに石がたまっていないか確かめましょう。
  • 終盤は自分の陣地に石を残しておくと、終了時にそのまま自分の点になります。

操作

  • 穴にカーソルを合わせると手袋が移動し、最後の1個が入る場所が光ります（ガイド。上のボタンでオン／オフ）。
  • クリックまたはタップで、その穴の石を配ります。
  • キーボードでは ← → で穴を選び、Enter で配ります。

マンカラの歴史

マンカラは一つのゲームの名前ではなく、穴に入れた石を順にまいていく「種まき」型のボードゲームをまとめた呼び名です。アラビア語の「動かす」という意味のことば（ナカラ）が由来とされています。

とても古くから遊ばれてきた遊びで、確かな証拠としては、エチオピアやエリトリアにあったアクスム王国の遺跡から6〜7世紀ごろの盤が見つかっています。さらに古い時代の石に彫られた穴の列を盤とみる説もありますが、はっきりとはわかっていません。地面に穴を掘り、木の実や小石を使えばどこでも遊べるため、アフリカ全体から中東、南アジア、東南アジアへと広がり、アフリカの人々とともにカリブ海の島々やアメリカ大陸にも伝わりました。

土地ごとに、穴の数やまき方の違うさまざまな遊び方があります。

  • オワレ（ガーナなど西アフリカ）：2列×6穴。ゴールはなく、相手の穴の石を取り合う
  • バオ（タンザニアなど東アフリカ）：4列×8穴の盤を使う、特にむずかしい遊び方
  • コンクラック（インドネシア）、チョンカック（マレーシア）：2列×7穴と両はしのゴール。舟の形をした盤も多い
  • パッランクリ（南インド）：2列×7穴。昔から家庭で遊ばれてきた

このゲームで使っている「カラハ」は、20世紀の半ばにアメリカで商品として売り出された遊び方です。ルールがわかりやすく、世界でいちばん広く遊ばれているマンカラになりました。
